## 这是什么

一本按「性价比」排序的运动书，专门写给**没时间去健身房的人**——主题是「最低有效剂量」：用最短的时间、最少的钱和意志力，换回最多的健康。每条建议写清三件事：**花掉什么**（钱、时间、毅力）、**换回什么**（心肺、肌肉、代谢、情绪、寿命）、**证据多硬**（A/B/C 三级）。来源只引期刊论文、官方机构报告（WHO、ACSM、AHA 等）和临床指南，不引二手转述。

它参考了 [eternity4719/HowToLiveBetter](https://github.com/eternity4719/HowToLiveBetter)（《高性价比人生指南》）与《高性价比饮食指南》《高性价比睡眠指南》的写法：同样是「成本 × 收益 × 证据等级」的条目制，同样是单文件、零依赖、手机可读的阅读页。饮食那本讲一日三餐，睡眠那本讲每晚那 6–9 小时，这本条讲怎么在没空、没钱、没意志力的情况下把身体活动塞进生活。

**本项目从未发行、也不会发行任何代币或数字资产。**

## 这本书想回答的问题

- 到底是谁说「必须练满 1 小时、必须去健身房」，最低有效剂量是什么？
- 剂量-反应曲线长什么样，性价比最高的拐点落在哪？
- 心肺耐力的最低剂量是多少，周末突击（周末战士）管不管用？
- 高强度间歇 HIIT 真的 15 分钟顶 1 小时吗，怎么安全地做？
- 力量训练的最低剂量是多少，在家练能不能替代健身房？
- 走路和 NEAT 为什么是最容易坚持的「运动药」？
- 运动零食（exercise snacks）是什么，怎么塞进碎片时间？
- 居家无器械、久坐打断、拉伸柔韧分别怎么用最少时间做？
- 怎么把运动塞进忙碌的一天，习惯怎么才不掉链子？
- 装备怎么花最少的钱，数据怎么别被它绑架？
- 出差、带娃、办公室、膝盖不好、老年人，各自怎么办？

## 重新生成

改完 `book/` 里的正文，重跑一次：

```
python build.py                # 渲染全部小节，输出 index.html
python build.py 1 3 7          # 只渲染指定小节
python build.py -o out.html    # 指定输出文件
```

零第三方依赖，Python 3.8+ 直接跑。统计数字（条目数、A/B/C、性价比三档）由脚本实时统计，写在页面页脚。

生成 PDF 版（需要 `pip install reportlab`，字体用系统自带中文字体，Windows/Linux 均可）：

```
python make_pdf.py                # 输出 how-to-exercise-better.pdf
python make_pdf.py -o out.pdf     # 指定输出文件
```

PDF 的封面、目录、前言、页眉页脚和书签由 `make_pdf.py` 自动生成，正文与统计数字同样来自 `book/` 与 `build.py` 的解析逻辑，两版内容永远一致。正文每次更新后，GitHub Actions 会同时重新生成 HTML 和 PDF 并自动提交。

改过页面交互脚本（`build.py` 里内嵌的 CSS/JS）后，跑一遍回归测试：

```
node tools/test_page.js        # 13 条断言：初始计数/章节单选/多选/开关/清空/URL
```

## 怎么贡献

正文按节拆成 16 个文件放在 `book/`，一条建议长这样：

```
### 1. 运动不是非得去健身房
<!-- 成本标签: 钱=0 时间=0 毅力=否 收益=中 口径=预期 -->
- 成本：零。
- 说人话：能让你心率上来、肌肉用到的身体活动都算运动——走路、爬楼、追公交、陪娃跑、居家自重训练都算，不是只有踩跑步机、举铁才叫锻炼。
- 收益：把"运动"的门槛从"必须办卡"降到"任何能动的时刻都算"，你立刻就有得做了。
- 证据等级：A
- 来源：WHO 2020 身体活动指南（明确把步行、骑车、家务、休闲活动都列入"身体活动"）；Bull FC 等 (2020). WHO 2020 guidelines. Br J Sports Med. <https://doi.org/10.1136/bjsports-2020-102955>
- 备注：WHO 把"身体活动"定义为任何由骨骼肌收缩产生、能量消耗高于静息的活动，不分场地。
```

字段顺序固定：成本 → 说人话 → 收益 → 证据等级 → 来源 → 备注。成本标签里：钱=0/少/多，时间=少/中/多，毅力=否/些/是，收益=大/中/小，口径=任意短词。性价比档由脚本按「收益量级 + 三项成本」自动算出。

**写新条目的三条规矩：**

1. 来源只引原始文献（期刊论文附 DOI 或官方链接）或官方文件；拿不准的数字标「待核实」，别硬编。
2. 「说人话」只用「收益」栏里已有的数字，不添新数，写成"哪些人、低几成"这样的日常说法。
3. 有争议的写在「备注」里，把反方证据列出来——本书不追求政治正确，追求可核对。

## 证据分级

| 等级 | 含义 |
| --- | --- |
| A | 有具体数字可查，出处是荟萃分析、大型队列或随机分组试验（RCT），或权威临床指南 |
| B | 有研究支持但说不出确切数字，或只有小样本、单项研究 |
| C | 作者经验、通行做法或官方科普，没有直接研究文献 |

**A 级只说明「有具体数字、出处可核」**，不说明一定是因果：观察性研究分不清是这件事起了作用还是做这件事的人本来就更健康；写着「随机分成两组」的才能说因果。本书面向普通健康人群，竞技训练另算。

## 性价比口径

证据等级回答「数字可不可信」，性价比回答「值不值得做」。每条按三项成本（钱、时间、毅力）加收益量级（大/中/小）自动归档：

- 好处大、三项成本全零 = **极高**
- 好处大、成本不高，或好处中等、成本为零 = **高**
- 其余 = **一般**

**这一档是作者自己的判断，不是证据**，按本书标准它本身只算 C 级。一条可以证据 A 级、性价比一般（如规范的老年防跌训练），也可以证据 C 级、性价比极高（把车停远一点多走几步）。「一般」不等于不该做。

**重要安全提示：** 本书是健康科普，不是医疗建议。如果你有心脏病、糖尿病、关节伤病、孕期等特殊情况，开始新运动前请先咨询医生或康复师，拿到适合你的「运动处方」再动（见第 16 节）。运动中若出现胸闷、眩晕、异常气短，立即停止并就医。
